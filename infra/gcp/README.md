# Infraestrutura GCP (planejada)

Este diretório documentará a estratégia de deploy no Google Cloud.

Direção inicial:

- execução de serviços em Cloud Run;
- banco gerenciado para produção;
- gerenciamento de segredos com serviço dedicado;
- pipeline de build e publicação de imagens.

O projeto ainda não possui infraestrutura de produção implementada.
