# Infraestrutura Docker (planejada)

Este diretório guardará artefatos de containerização quando backend e frontend estiverem prontos para execução integrada.

Planejamento inicial:

- Dockerfile do backend FastAPI;
- Dockerfile do frontend React;
- orquestração local via docker compose;
- padronização de ambiente de desenvolvimento.

Nenhum deploy em container está implementado neste momento.
