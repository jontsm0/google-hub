# Frontend — Google Hub

Frontend planejado em React + TypeScript para entregar o dashboard unificado do projeto.

## Estado atual

Estrutura de diretórios inicial preparada para evolução do aplicativo:

- `src/pages`: páginas da aplicação
- `src/components`: componentes reutilizáveis
- `src/services`: comunicação com backend
- `src/types`: contratos e tipagens
- `src/layouts`: layout base

## Entrypoint planejado

Na fase de implementação do frontend, o entrypoint seguirá o padrão React moderno:

- `src/main.tsx` inicializando a aplicação;
- `src/App.tsx` compondo rotas e layout principal.

Este frontend ainda está em fase de scaffold e não possui aplicação executável completa.
