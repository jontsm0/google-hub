**Novo projeto: Google Hub**

Estou iniciando o desenvolvimento do **Google Hub**, uma aplicação pessoal criada para centralizar informações de diferentes serviços do ecossistema Google em uma única experiência.

A ideia surgiu ao perceber que ferramentas como Google Drive, Google Calendar, Google Tasks, Gmail e Gemini são poderosas, mas normalmente ficam distribuídas em ambientes separados. O objetivo do projeto é criar uma camada de organização que conecte esses serviços e permita visualizá-los em torno de projetos, tarefas e atividades.

A primeira versão será desenvolvida com:

- Python
- FastAPI
- React
- TypeScript
- SQLite
- SQLAlchemy
- APIs do Google
- OAuth 2.0

O projeto também nasceu a partir do estudo do repositório **9Drive**, utilizado como referência para compreender como uma aplicação pode conectar-se a serviços externos, gerenciar autenticação, armazenar tokens com segurança e apresentar os dados em uma interface própria.

O objetivo não é substituir as aplicações oficiais do Google, mas criar um hub contextual que permita:

- visualizar arquivos recentes do Google Drive;
- acompanhar próximos eventos do Google Calendar;
- consultar tarefas pendentes;
- organizar recursos dentro de projetos;
- relacionar arquivos, eventos e tarefas;
- abrir recursos diretamente nas ferramentas oficiais;
- futuramente utilizar inteligência artificial para resumos e sugestões.

Este projeto também é uma oportunidade para aplicar e aprofundar estudos em desenvolvimento backend com Python, construção de APIs REST, integração com APIs externas, autenticação OAuth 2.0, modelagem de dados, frontend, arquitetura modular, testes, documentação e deploy em nuvem.

O desenvolvimento será incremental, começando por um MVP com Google Drive, Google Calendar, Google Tasks e um dashboard central.
